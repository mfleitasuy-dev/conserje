# ADRs — Registros de decisiones de arquitectura

Un ADR (Architecture Decision Record) documenta una decisión técnica significativa: el contexto
en que se tomó, la decisión en sí y sus consecuencias (buenas y malas). Se escriben una vez y
no se editan: si una decisión cambia, se agrega un ADR nuevo que reemplaza al anterior.
